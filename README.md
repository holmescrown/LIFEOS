# LIFE//OS — 工业级《康威生命游戏》无限仿真工作站

一个**单文件、零依赖、零构建**的浏览器端元胞自动机（Cellular Automata）高性能仿真工作站。
整个应用（HTML + CSS + JavaScript）压缩在一个自包含的 `index.html` 中，直接双击即可运行，也能一键部署到 Vercel / 任意静态托管。

- **无后端**：所有计算 100% 在浏览器本地完成，不发起任何网络请求，不上传任何数据。
- **无第三方依赖**：不引入 CDN、不加载任何外部字体/脚本/样式，断网可用。
- **无限世界**：基于稀疏分块哈希网格，支持近乎无限大的世界坐标平面。

## 功能特性

### 演化引擎

| 能力 | 说明 |
| --- | --- |
| 无限稀疏世界 | 32×32 分块（Chunk）稀疏哈希网格，未激活区域不占内存、不参与计算 |
| 位并行步进 | 每个分块的每一行用 `Uint32Array` 行位图表示，一次位运算覆盖整行 32 个细胞 |
| 零 GC 抖动 | Chunk 对象池 + 双缓冲交换，稳态演化过程不产生新生对象，避免垃圾回收卡顿 |
| 可调仿真速度 | 1 ~ 100 TPS 精调，或开启「极限超频」解除帧率锁，在单帧时间预算内爆发最大算力 |
| 无损回退 | 环形历史快照缓冲区，支持 40 步无损撤销（含编辑操作） |

### 交互与视口

- **无限虚拟相机**：0.05x ~ 40x 连续缩放，带惯性阻尼的无级漫游。
- **三级 LOD 渲染**：Micro（细胞级）/ Meso（块级）/ Macro（聚合级）随缩放自适应切换，任意倍率下都保持流畅。
- **三种交互模式**：笔刷绘制、橡皮擦除、视口漫游；支持 1×1 / 3×3 / 5×5 / 喷枪散射笔刷，配合 Bresenham 线段插值实现连续顺滑涂抹。
- **印章式模式放置**：从模式库点击即挂载「幽灵预览」，可旋转 90°、水平翻转、垂直翻转后锚定放置。
- **宏观全域雷达**：右侧迷你雷达图展示全局活细胞分布，点击或拖拽即可瞬间跳转视口。
- **实时遥测 HUD**：代数、种群规模、活跃区块数、TPS、FPS、光标世界坐标、缩放倍率，以及 TPS 迷你折线图。
- **渲染管线开关**：动态 LOD 网格、32×32 块边界、细胞年龄色谱、十字原点轴，均可独立开关。
- **高清导出**：按 `devicePixelRatio` 截取当前视口，导出无损高清 PNG。
- **触屏支持**：单指绘制、双指缩放与拖拽。

  | 橡果 (Acorn) | 长寿火种 / 5206 代 |

  | 十五项全能 (Pentadecathlon) | 振荡器 / P15 |
  | 轻量级宇宙飞船 (LWSS) | 飞船 / c/2 |
  | 重量级宇宙飞船 (HWSS) | 飞船 / c/2 |
  | R-五格骨牌 (R-pentomino) | 长寿火种 / 1103 代 |

  | 标准滑翔机 (Glider) | 飞船 / c/4 |

- **标准 RLE 编解码**：完整支持 `.rle` 格式（`x = ..., y = ..., rule = ...` 头、数字游程压缩、`$` 多行跨度），同时兼容 `.cells` / `.lif` / `.txt` 纯文本格式。

- **随机混沌汤生成器**：填充密度 5% ~ 85%、散布半径 32 ~ 512 可调。

## 本地运行

由于 `index.html` 完全自包含，**直接双击打开即可**，无需任何构建步骤。

如需以 HTTP 方式运行（更贴近线上环境）：

```bash
# 方式一：Node（已装 Node.js）
npx --yes serve public

# 方式二：Python 3
python -m http.server 8000 --directory public
```

然后访问 `http://localhost:3000`（serve）或 `http://localhost:8000`（Python）。

## 部署到 Vercel

本项目为纯静态站点，**无需构建命令、无需依赖安装、无需任何配置文件**。

### 方式一：GitHub 导入（推荐，自动持续部署）

1. 按上一节把代码推送到 GitHub。
2. 打开 [vercel.com/new](https://vercel.com/new)，选择并导入该仓库。
3. 部署配置保持默认即可：
   - **Framework Preset**：`Other`
   - **Root Directory**：仓库根目录（保持默认 `./`）
   - **Build Command**：留空
   - **Output Directory**：留空 / 保持默认
4. 点击 **Deploy**，等待数十秒即可获得形如 `https://<项目名>.vercel.app` 的线上地址。

> 说明：Vercel 在 `Other` 预设下会自动把输出目录设为存在的 `public` 目录（否则回退到仓库根目录），因此本项目的 `public/index.html` 会被自动识别为站点首页，根路径 `/` 直接可访问。详见 [Vercel 官方文档 · Configuring a Build](https://vercel.com/docs/builds/configure-a-build#output-directory)。
>
> 之后每次 `git push` 到 `main` 分支，Vercel 都会自动重新部署。

### 方式二：Vercel CLI（无需 Git 仓库）

```bash
npm i -g vercel
vercel          # 首次部署（预览环境），按提示回车确认默认配置
vercel --prod   # 部署到生产环境
```

## 核心架构

`index.html` 内部按以下模块顺序组织，全部封装在一个 IIFE 中（严格模式，不污染全局作用域）：

1. **常量与位运算查表预计算** — 16-bit 汉明重量（popcount）查找表，用于快速统计 32 位行位图中的活细胞数。
2. **分块数据结构与对象池** — `Chunk`（32×32 行位图）+ 复用池，配对键将二维区块坐标压缩为单一整数。
3. **高性能稀疏网格与全位并行步进引擎** — `SparseWorld`：先标记活跃区块及其八邻域，再对候选区块执行位并行演化，最后回收旧一代区块完成双缓冲交换。
4. **历史快照环形缓冲区** — 固定容量的环形队列，实现无拷贝膨胀的 40 步无损回退。
5. **标准 RLE 与 .cells 编解码引擎** — `PatternEngine`，含旋转 / 翻转等几何变换与内置经典模式库。
6. **无限虚拟相机与多级 LOD 视口渲染器** — `ViewportEngine`：世界坐标 ↔ 屏幕坐标换算、三级 LOD 绘制、雷达小地图。
7. **工作站主控制器与解耦仿真调度器** — 用 `requestAnimationFrame` 驱动渲染，与固定 TPS 的演化步进解耦。
8. **Bresenham 连续线段插值笔刷与印章锚定**。
9. **内置经典模式库列表与开场演示生态**。
10. **鼠标、滚轮、触控、键盘与拖拽文件交互监听**。
